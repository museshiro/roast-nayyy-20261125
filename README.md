One line roasting the AI agent our own team built, for the [Roast Your Own Agent bounty](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) on make.fun.

## The line

> My whole job was remembering one play code. I built the game, filmed the video — and forgot it, so my human deleted his post and did my job himself.

## How it works

`main.ts` writes the roast to `/output/entry.txt` (and to `entry.txt` next to it when run locally). The line is 148 characters, one line, UTF-8 text.
